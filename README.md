# 描工房（えがこうぼう）

iPad（Apple Pencil）で描く、イラスト・マンガ・Webtoon・アニメーション制作アプリ。ブラウザで動く日本語版です。
インストール不要、Safari で開いて「ホーム画面に追加」するとアプリとして使えます（オフラインでも開けます）。

**現在の版: v1.0.0（全7フェーズ完了）**

## できること（v0.1）
- **作品一覧**: 新規作成（イラスト・マンガ原稿・Webtoon・アニメ・SNS・グッズのプリセット）、画像から作成、
  名前の変更・複製・削除、作品ファイル（.egk）の書き出しと読み込み
- **ブラシ**（筆圧・傾き・手ブレ補正・入り抜き・紙の質感）
  - ペン: Gペン／丸ペン／カブラペン／ミリペン／マーカー／塗りペン
  - 鉛筆: 鉛筆／シャープペンシル／色鉛筆
  - 筆: 透明水彩／不透明水彩／平筆
  - エアブラシ: 柔らか／強め
  - 消しゴム: 硬め／軟らかめ／ざっくり
- **塗りつぶし**: 他レイヤーを参照・編集レイヤーのみ・参照レイヤーを参照（色の誤差・隙間閉じ・領域拡縮）、囲って塗る／囲って消す
- **色**: 色相環、HSV スライダー、メイン／サブ／透明色、履歴、カラーセット
- **レイヤー**: フォルダー、クリッピング、描画モード（乗算・スクリーン・オーバーレイ・加算 など）、不透明度、
  透明ピクセルをロック、ロック、参照レイヤー、下描きレイヤー（書き出さない）、下のレイヤーに結合、用紙の色
- **表示**: 拡大縮小・回転・左右反転・全体表示
- **書き出し**: PNG（大きな原稿もそのままの大きさ・dpi 付き）・JPEG、共有シートで「写真に保存」「ファイルに保存」
- 自動保存（iPad の中に保存）

### v0.2 で増えたこと
- **選択範囲**: 長方形・楕円・投げなわ・折れ線・自動選択・選択ペン・選択消し（新規／追加／削除／共通）。
  選択中は画面の下に操作バー（解除・反転・拡大縮小・消去・範囲外消去・塗りつぶし・新しいレイヤーに写す・広げる・縮める）
- **変形**: 拡大・縮小・回転／自由変形／メッシュ変形、左右・上下反転（⌘T。画像を読み込むとすぐ変形になります）
- **コピー・切り取り・貼り付け**（⌘C / ⌘X / ⌘V）
- **図形**: 直線・長方形（角丸）・楕円・多角形（線／塗り／線と塗り）
- **グラデーション**: メインからサブ・メインから透明・円形
- **テキスト**: 縦書き・横書き、ルビ（「｜親文字《おやもじ》」または「漢字《かんじ》」）、フチ、アンチック風（漢字ゴシック＋かな明朝）・ゴシック・明朝・丸ゴシック
- **色調補正**: 明るさ・コントラスト、色相・彩度・明度、レベル補正、トーンカーブ、カラーバランス、階調の反転、ポスタリゼーション、2階調化、
  グラデーションマップ。レイヤーに直接かけるほか、あとから直せる**色調補正レイヤー**にもできます
- **フィルター**: ぼかし、シャープ、モザイク、ノイズ、輝度を透明度に変換（スキャンした線画を塗れる線画に）
- **レイヤーマスク**: 作成・選択範囲外をマスク・有効/無効・適用・削除（マスクのサムネイルを押すとマスクに描けます）
- **ベクターレイヤー**: 描いた線をあとから直せます。消しゴムで「触れた部分／交点まで／線全体」、線修正ツールで太く・細く
- テキスト・ベクターの**ラスタライズ**

### v0.3 で増えたこと（マンガ）
- **コマ枠**: マンガ → コマ枠を作成（基本枠の余白を mm で指定）。コマ枠ツールの「枠線分割」でコマを割ります
  （横に割ると上下の間隔、縦に割ると左右の間隔が空きます）。コマの中に描いた絵は枠の外にはみ出しません。角の移動・長方形のコマも
- **トーン**: マンガ → トーンを貼る（選択範囲に、線数・角度・網点／線／格子／砂目）。トーンのレイヤーに黒で描くとその濃さのトーン、
  消しゴムで削れ、グラデーションでグラデーショントーンになります。どのレイヤーでも「トーンにする」でトーン化できます
- **効果線**: 集中線・流線・ウニフラ（本数・太さ・ばらつき・まとまり）。新しいレイヤーに描きます
- **フキダシ**: 楕円・角丸・モコモコ・トゲ、しっぽ。あとから選んで動かせます（文字はテキストツールで）
- **定規**: 直線・平行線・放射線（集中線）・同心円・パース（1点・2点）・対称（鏡・回転）。ペンが定規に吸い付きます。
  画面上の「定規」ボタンで吸い付きをオン・オフ
- **モノクロ**: レイヤーの表現色をモノクロ（2値）に、画面をモノクロ2値で表示、**2値 PNG（1ビット）** で書き出し（モノクロ原稿の入稿用）

### v0.4 で増えたこと（複数ページ）
- **複数ページの作品**: 新規作成で「ページ数」を 2 以上に（あとからでも ファイル → ページ管理 で足せます）
- **ページ管理**: 見開きで並べて表示。ページの追加・複製・削除・並べ替え、見開きページ（2ページ分の横長）。
  編集画面の上の ◀ ▶（PageUp / PageDown）でページを移動、番号を押すとページ管理へ
- **作品の設定**: 仕上がりサイズ（B5・A4・A5・B6・ポストカード・自由）、裁ち落とし、基本枠、右綴じ／左綴じ、開始ページ、ノンブル（位置・大きさ・最初の番号）
- **ガイド**: 仕上がり線・基本枠・のど・ノンブルの位置を画面に表示（表示メニューで切り替え）。コマ枠の基本枠もこの設定に合わせます
- **書き出し**: ファイル → 書き出し… で、このページ／全ページ（zip）／見開きの確認用 JPEG、形式（カラー PNG・2値 PNG・JPEG）、
  大きさ（裁ち落とし込み・仕上がりで切る・トンボを付ける）、ノンブルを入れる
- **Webtoon**: ファイル → Webtoon 用に分割して書き出す（高さを指定して連番の画像に）
- 作品ファイル（.egk）が複数ページの作品にも対応

### v0.5 で増えたこと（アニメーション）
- **アニメーションの新規作成**: 新規作成の「アニメーション」で、背景レイヤーとアニメーションフォルダー（セル 1）から始まります。
  どの作品でも レイヤー → 新規アニメーションフォルダー で作れます
- **タイムライン**（表示 → タイムライン）: フレームを押して移動、セルを押すとセルの指定・空セル・新しいセル・キーの削除・ライトテーブル。
  「＋次の絵」でコマ打ち（1〜4コマ）の数だけ進めて新しいセル。fps（6〜30）・長さも設定できます
- **オニオンスキン**（前のセルは青、次のセルは緑で薄く表示）、**ライトテーブル**（下絵にするセルをいつも薄く表示）
- **カメラワーク**: タイムラインの「カメラ」で枠を表示。枠を動かす（中＝移動・角＝拡大縮小・丸＝回転）と、そのフレームにキーを打ちます。
  キーの間はなめらかに動きます
- **再生**（▶）: フレームを準備してからプレーヤーで再生（くり返し）
- **書き出し**: MP4（H.264）・GIF・連番 PNG（zip）。出力の大きさ（カメラの枠）と倍率を選べます
- キーボード: , と . で前後のフレーム、Shift＋. で次の絵

### v0.6 で増えたこと（印刷・グッズ）
- **PDF 入稿**: ファイル → 書き出し… → PDF。色は カラー（RGB）／グレー／2値（1ビット）／CMYK（簡易変換）。
  トンボ・ノンブル・仕上がりで切る も PNG と同じように選べ、仕上がり枠（TrimBox）・裁ち落とし枠も入ります。全ページは1つの PDF に
- **PSD（レイヤー付き）**: フォルダー・クリッピング・描画モード・不透明度・マスク・日本語のレイヤー名をそのまま。
  トーンは網点の見た目、コマ枠は「枠の形のマスク付きグループ＋枠線」、下描きは非表示で入ります（色調補正レイヤーは入りません）
- **グレー PNG**（グレースケール入稿用）
- **グッズ用テンプレート**（新規作成の「グッズ・印刷物」）: 缶バッジ 32／44／57／76mm（巻き込み・表示面・安全範囲のガイド）、
  アクリルスタンド A6、アクリルキーホルダー、ステッカー、ポストカード、A3・B2 ポスター
- **カットライン・白版**: マンガ → カットライン・白版を作る。絵の外形から指定の距離（mm）でカットラインを作り、白版（絵の形の黒）も作れます。
  ファイル → 作業レイヤーだけを PNG で書き出す で、白版・カットラインを別のファイルにできます
- **CMYK プレビュー**（表示メニュー）: 印刷したときのくすみ方の目安を画面で見られます

### v1.0 で増えたこと（効率化）
- **クイックアクセス**: 絵の右端のボタン列に、サブツール・色・メニューのコマンド・オートアクションを置けます（＋で追加、長押しで並べ替え・外す）
- **オートアクション**（表示 → オートアクション…）: メニューの操作を記録して、ボタン1つで続けて実行
- **ショートカット設定**（表示 → ショートカット設定…）: 項目を押してからキーを押すと割り当て
- **素材**（右パネルの「素材」タブ）: 作業レイヤー（選択範囲があればその中）を素材に保存し、押すと貼ってすぐ変形。
  トーン（10〜70%）・パターン（市松・ストライプ・水玉・青海波・格子・麻の葉）もすぐ貼れます
- **左利きの配置**（表示メニュー）: 道具を右、パネルを左に
- **作業時間**: 作品一覧と作品の情報に表示
- **タイムラプス**（ファイル → タイムラプスを記録する）: 描く過程を記録して MP4 に
- **描き味**: ペン先の先読み（届く前の位置を薄く描いて遅れを小さく）

## 操作
| 操作 | 動き |
|---|---|
| 2本指でつまむ・ひねる | 拡大縮小・回転・移動 |
| 2本指タップ | 取り消し |
| 3本指タップ | やり直し |
| 指で長押し | スポイト |
| 1本指ドラッグ | 画面の移動（Apple Pencil を使うと自動で「指では描かない」になります） |
| Apple Pencil を浮かせる | ブラシの大きさを表示（ホバー） |
| 画面左端のスライダー | ブラシサイズ・不透明度 |
| 使っているツールをもう一度押す | ツールの設定を出す／しまう |

キーボード（Magic Keyboard）: P ペン／N 鉛筆／B 筆／A エアブラシ／E 消しゴム／G 塗りつぶし／I スポイト／V 移動／H 手のひら／
Z 虫めがね、⌘Z 取り消し／⇧⌘Z やり直し、[ ] ブラシサイズ、X メイン↔サブ、C 透明色、⇧H 左右反転、⌘0 全体、⌘1 100%、
Tab パネル、スペース＋ドラッグ 移動、⌘E 下に結合、⇧⌘N 新規レイヤー、M 選択範囲／U 図形／J グラデーション／T テキスト／Q 線修正／K コマ枠／F フキダシ／L 効果線／R 定規、⇧R 回転、
⌘A すべてを選択、⌘D 選択を解除、⇧⌘I 選択範囲を反転、⌘T 変形（Enter で確定・Esc で取り消し）、Delete 選択範囲の中を消去。

## 注意
- 作品は iPad の Safari の中（このアプリ専用の保存領域）に保存されます。大事な作品は「作品ファイル（.egk）で書き出す」で
  ファイルにも残してください。
- Apple Pencil Pro のスクイーズとダブルタップは、Web アプリには届かないため使えません（2本指・3本指タップで代用）。
